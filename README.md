# Hostel Reservation System

A web-based **Hostel Reservation System** developed using **PHP and MySQL** to simplify and manage the hostel room booking process. The system provides separate functionalities for **users and administrators**, allowing users to register, log in, view available rooms, make reservations, and manage their bookings, while administrators can manage users, rooms, and reservations through an admin dashboard.

## Key Features

- 🔐 **User Registration & Login** – Secure user authentication and account management.
- 🏨 **Room Reservation** – Users can view available hostel rooms and make bookings.
- 📋 **Booking Management** – Users can view and manage their reservation details.
- 👨‍💼 **Admin Dashboard** – Administrators can monitor and manage hostel reservations.
- 🛏️ **Room Management** – Manage room availability and booking information.
- 🔑 **Admin Authentication** – Separate login system for administrators.
- 🚪 **Logout Functionality** – Secure session logout for users and administrators.
- 🗄️ **Database Management** – MySQL database used to store user, room, and booking information.

## Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Version Control:** Git & GitHub

## Project Objective

The main objective of this project is to provide a simple and efficient platform for managing hostel reservations digitally. It reduces manual booking processes and provides hostel administrators with an organized way to manage users, rooms, and reservations.
